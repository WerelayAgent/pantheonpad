# PantheonPad 🏛️

**PantheonPad** is a multichain token launchpad inspired by the ancient Greek Pantheon.
Where tokens begin — launch for free on Pantheon (bonding curve that graduates to Uniswap v4 with locked liquidity) and pump.fun simultaneously, paid in SOL or HYPE.

## Features
- **Multichain Launch**: Launch tokens with bonding curves graduating to Uniswap v4 + pump.fun
- **Dual Currency Support**: SOL & HYPE
- **Ancient Mythological Theme**: Classical gold and dark navy aesthetic
- **Instant Swap & Trade**: Interactive DEX charting and bonding curve progress

## Tech Stack
- React SPA
- Vite
- Tailored for high-performance static hosting on Vercel
